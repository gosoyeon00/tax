# 세금 떼어두기

https://taxaside.co.kr — 1인 사업자·프리랜서·방송인이 들어온 돈과 쓴 돈을 적으면 앞으로 낼 부가세·종합소득세와 지금 떼어둘 돈을 계산해 주는 웹앱.

## 배포

- GitHub Pages가 `main` 브랜치의 파일을 그대로 올립니다. `main`에 올리면 1~2분 뒤 사이트에 반영됩니다.
- `CNAME`이 `taxaside.co.kr`을 가리킵니다. 지우면 주소 연결이 끊깁니다.
- 앱은 `index.html` 한 파일입니다(빌드된 결과물). 고칠 때 쓰는 원본 코드는 이 저장소에 없습니다.
- `lib/xlsx-0.20.3.full.min.js`: 카드 내역(xlsx·csv)을 읽는 SheetJS 0.20.3. 2026-10-16 cdn.sheetjs.com에서 받은 원본입니다. sha384-EnyY0/GSHQGSxSgMwaIPzSESbqoOLSexfnSMN2AP+39Ckmn92stwABZynq1JyzdT

원본에서 새 `index.html`을 만들면 아래 내용이 빠집니다. 새 버전을 만들 때 원본에도 똑같이 넣어 주세요.

## 서버 (Supabase)

- 계정·동기화에 Supabase를 씁니다. 기록은 기기에서 암호화한 뒤 `records` 테이블에 올라갑니다.
- 점검할 것: `records` 테이블의 RLS(행 단위 보안)가 켜져 있고 정책이 본인 행만 허용하는지(`auth.uid() = user_id`), `delete-account` 함수가 로그인한 본인만 지우는지.
- 무료 요금제는 7일 동안 요청이 없으면 일시정지되고 자동 백업이 없습니다.
